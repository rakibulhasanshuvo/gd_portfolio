## 🎨 Overview & Design Architecture

This portfolio is an interactive digital experience engineered to showcase commercial print craftsmanship, brand identity systems, and high-velocity digital marketing assets. Combining raw brutalist typography, authentic photocopy paper textures, and tactile audio feedback, it translates tactile physical print media into the digital browser.

### Key Highlights & Showcase Volumes

1. **VOL — 01 // Packaging Fleet**
   - **500+ commercial shopping bag production runs** delivered across high-street apparel, boutique luxury brands, and athletic retail.
   - Interactive dual-mode visualizer: seamless toggle between photorealistic physical 3D bag mockups and ultra-crisp vector production plates.
   - Flagship projects: *OFFGRID Tactical Wear*, *Stylex Wear*, *Mivara Fashion House*, and *OME Sports Zone*.

2. **Interactive Prepress Engineering Darkroom**
   - Simulated prepress color separation console inspecting spot color channels, registration crosshairs, die-cut crease lines, and substrate textures.
   - Live toggles for **Die-Line**, **Spot Color Plate**, **Key Black (K)**, and **Kraft Substrate**.
   - Technical specifications for screen-print mesh counts (120T–140T), trapping margins (±0.2mm), and ink viscosities.

3. **VOL — 02 // Corporate Brand Identity Systems**
   - Complete visual identity programs including geometric mark construction, grid geometry, typography scale, color lockups, and real-world brand collateral mockups.
   - Featured identities:
     - `SYNQ Health` — Telehealth & biometric diagnostics platform.
     - `Mailtrum Cloud` — Privacy-first transactional developer mail protocol.
     - `BTV 2.0 National Media` — Modern broadcast network rebrand.
     - `Shuvo Monogram` — Personal isometric dimensional monogram mark.

4. **VOL — 03 // Posters & High-Impact Print Showcase**
   - Commercial print flyers, large-format event posters, and hospitality menus:
     - `PRT-001` Back-to-School Campus Showcase Poster (A2 300 DPI)
     - `PRT-002` Apex Corporate Growth Strategy Flyer
     - `PRT-003` ECHO CHAMBER // 12-Hour Underground Audio Rave Festival Poster
     - `PRT-004` Taste the Flavor // Saffron & Smoke Buffet Promotional Flyer
     - `PRT-005` Adeline Architects Swiss Modernist Exhibition Wireframe Poster
     - `PRT-006` Atelier Bread & Roastery Autumn Table Card Menu
     - `PRT-007` Black & Gold Modern Dining Diamond Grid Menu
     - `PRT-008` Fashion Factory Big Summer Sale Window Campaign Poster

5. **Viral Media & YouTube Creative Direction**
   - High-CTR editorial thumbnail gallery featuring split-testing layouts, dynamic badges, view statistics, and modal inspection.

6. **Tactile Sound System**
   - Custom synthesized Web Audio API sound design: authentic physical mechanical clicks, dial turns, and channel switches with zero external audio assets.

## ⚡ Performance & Engineering

- **Turbopack Build Engine**: Instant static page compilation in Next.js 16.
- **CSS Content Visibility**: Modern `content-visibility: auto` layout containment for below-the-fold sections, reducing initial DOM evaluation by **>22%**.
- **Asset Optimization**: High-efficiency progressive encoding and lossless vector delivery saving **>11.9 MB** in payload footprint.
- **Zero CLS**: Stable layout shifts score (`CLS: 0.00`) verified via Chrome DevTools.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.18+ or 20+
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/rakibulhasanshuvo/gd_portfolio.git

# Navigate to project directory
cd gd_portfolio

# Install dependencies
npm install
```

### Local Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Compile and build static production bundle
npm run build

# Start production server
npm run start
```

### Linting & Type Checking

```bash
npm run lint
npx tsc --noEmit
```
